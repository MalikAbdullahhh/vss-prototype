# Virtual Study Space — Frontend Prototype

A complete React frontend prototype for the VSS Final Year Project.

## Tech Stack
- React 18 + Vite
- React Router DOM (client-side routing)
- Recharts (charts)
- DM Sans + Playfair Display (Google Fonts)

## Setup & Run

```bash
# 1. Extract the zip
# 2. Navigate into the folder
cd vss-frontend

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Build for production
npm run build
```

## Pages / Routes

| Route | Page |
|-------|------|
| `/` | Landing Page |
| `/login` | Login |
| `/signup` | Sign Up Step 1 |
| `/signup/step2` | Sign Up Step 2 |
| `/app` | Dashboard |
| `/app/profile` | User Profile |
| `/app/notes` | Notes Editor |
| `/app/ai` | AI Study Assistant |
| `/app/chat` | Chat / Rooms Chat |
| `/app/leaderboard` | Leaderboard |
| `/app/rooms` | Browse Rooms |
| `/app/rooms/:id` | Room Detail (Video + Chat) |
| `/app/study-tools` | Pomodoro + Planner + Notes |
| `/app/files` | Saved Files + Upload Modal |
| `/app/achievements` | Achievements & Badges |

## Login (demo)
Just click "Log In" — no real credentials needed for the prototype.
The auth system is simulated with React context.
